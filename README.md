# Zomato Restaurant Analytics and Clustering

An end-to-end data analytics and machine learning project focused on restaurant analysis, customer review sentiment analysis, and restaurant clustering using Zomato datasets.

## Objectives

- Analyze restaurant metadata and customer reviews.
- Perform exploratory data analysis.
- Analyze customer sentiment.
- Cluster restaurants into meaningful segments.
- Generate business insights and recommendations.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLTK
